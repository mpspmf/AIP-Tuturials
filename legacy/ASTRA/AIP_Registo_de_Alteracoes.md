# Registo completo de alterações

## Atualização sobre o Outlook clássico

Verificação concluída: 26 páginas; 40 imagens preservadas; índice e legendas atualizados. Foram registadas 20 alterações nesta atualização.

Esta atualização substitui o percurso manual do capítulo 10 por um envio em série a partir do Word através do Outlook clássico. Mantêm-se o Teams como ponto de partida e o novo Outlook para uso diário. Os registos da revisão anterior ficam abaixo como histórico.

### O04 Parágrafo 25 da versão revista

**Antes**

O Excel e o Word, utilizados em conjunto, permitem preparar emails personalizados. Use o Excel para organizar a lista de destinatários e os campos associados a cada um. Use o Word para preparar o corpo do email e substituir os campos pelos valores da lista. O envio direto a partir do Word requer um programa de correio compatível e não funciona com o novo Outlook; consulte o capítulo 10 para concluir o processo.

**Depois**

Use o Excel para organizar os destinatários e os campos de personalização. Use o Word para preparar o modelo e substituir os campos pelos valores da lista. Para enviar os emails em série a partir do Word, utilize o Outlook clássico para Windows, conforme o capítulo 10. O novo Outlook não permite este envio direto.

### O05 Parágrafo 166 da versão revista

**Antes**

Com o novo Outlook, use os passos seguintes para gerar os textos e preparar cada mensagem individualmente.

**Depois**

Para enviar emails personalizados em série, utilize Excel, Word e Outlook clássico para Windows. O Word entrega as mensagens ao Outlook através da integração MAPI, que o novo Outlook não suporta. Neste capítulo, o envio é feito pelo Outlook clássico; pode continuar a usar o novo Outlook no trabalho diário.

### O17 Parágrafo 185 da versão revista

**Antes**

Para enviar a partir de uma caixa de correio partilhada, como geral@... ou suporte@..., selecione esse endereço no campo “De”; se necessário, escolha “Outro endereço de email”. Precisa de permissão para “Enviar como” ou “Enviar em nome de”, atribuída pelo administrador. Uma caixa partilhada não exige iniciar sessão diretamente com uma palavra-passe própria nem criar um perfil exclusivo de Outlook.

**Depois**

Para enviar a partir de uma caixa partilhada, como geral@... ou suporte@..., é necessária a permissão “Enviar como” ou “Enviar em nome de”. A caixa aparecer na lista de pastas não garante que esteja disponível como conta remetente para a impressão em série. Peça à equipa de informática que valide a configuração no Outlook clássico e confirme-a num teste. Não é necessário iniciar sessão diretamente na caixa partilhada com uma palavra-passe própria.

## Fontes das correções técnicas

- [Microsoft — Atalhos de teclado do Teams](https://support.microsoft.com/en-US/Accessibility/teams/keyboard-shortcuts-for-microsoft-teams): Ctrl + Enter na caixa de composição expandida.
- [Microsoft — Impressão em série no Word](https://support.microsoft.com/en-gb/word/use-mail-merge-in-word-to-send-bulk-email-messages): o envio direto exige um programa compatível com MAPI.
- [Microsoft — Comparação de funcionalidades do Outlook](https://support.microsoft.com/en-us/outlook/getstarted/feature-comparison-between-new-outlook-and-classic-outlook): o novo Outlook não suporta MAPI.
- [Microsoft — Utilizar uma caixa de correio partilhada](https://support.microsoft.com/en-us/outlook/sharing/open-and-use-a-shared-mailbox-in-outlook): utilização do campo De, permissões e ausência de início de sessão direto na caixa partilhada.
